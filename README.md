# platform-slides

A silent, presenter-driven web keynote built on React, Three.js, and GSAP.

```bash
npm install
```

```bash
npm run dev
```

Open `http://localhost:5173`. Press the arrow keys to move through the show. Press `D` to show or hide the debug panel.

The docs are in [docs/README.md](docs/README.md). Rules for agents are in [AGENTS.md](AGENTS.md).
