# Inspiration references

These sites set the level of ambition for the keynote. Study them for pacing, transitions, camera work, and art direction. Do not copy their assets, text, or code.

The Monolith Project is the main reference for the art: its look, its mood, and its visual quality.

Most of these sites are driven by scroll and some use sound. In this keynote, the presenter drives the playhead and there is no sound. Take the visual ideas, not the input model or the audio.
