# Keynote reconstruction

The presenter approved the current order on 2026-10-05.

## Story

1. The cover introduces the topic and the speaker.
2. The engineer supplies context and reviews the agent on a PC.
3. The assessment distinguishes individual adoption from team maturity.
4. Instructions become prompts, skills, agents, plugins, guardrails, a Harness, and asynchronous work.
5. Platform supplies four repositories and defines Discovery, Foundations, and Maintenance.
6. Foundations encodes the stack, boundaries, observable behavior, and owner checkpoints.
7. agent-harness installs the agent environment, including procedures, tools, repository context, and OpenSpec.
8. Events run bounded workers. Normal jobs prepare facts, agents reason, and fixed code validates and applies allowed outputs.
9. Health measures delivery, agent work, and human attention. Audit findings return to Refine.
10. A person close to the product files a small eligible Issue or bug that reaches production without human supervision.

Refine and Implement get separate close views.
Questions return to the author, large work splits, and repairs and reviews return through CI.
Merge Gate owns merging. Release starts manually.
The final world does not claim a measured maturity score.
Early work establishes the technical and agent base. Later work puts more effort into product definition.
The closing world shows why the earlier layers exist: product experts can ship bounded changes through the completed route.
